CONFIGURATION :
- Variables d'environnement (OAuth, Merchant, Endpoints, URLs)
- Endpoints API (OAuth, WebPay, TransactionStatus)
- Gestion automatique localhost (3 solutions)

FLUX DE PAIEMENT :
- Diagramme de séquence complet
- OAuth → WebPayment → Redirect → OTP → Webhook → Return
- Détail de chaque étape avec logs

IMPLÉMENTATION :
- Service orange_money.py (get_access_token, create_payment_request, 
  check_transaction_status, verify_webhook)
- Vues Django (orange_start_payment, orange_return, orange_notify)
- URLs configurées (/buy/om/, /payments/om/return/, /payments/om/notify/)
- Logging complet (format [OM][fonction] message | key=value)

TESTS :
- Commande : python manage.py test_orange_money_sandbox --amount 100
- Vérification statut : --check-status ORDER_ID --pay-token TOKEN
- Exemples de logs attendus

TROUBLESHOOTING :
- Erreur OAuth (401/403) → Vérifier CLIENT_ID/SECRET
- Erreur WebPay (400/403) → Vérifier MERCHANT_KEY ou URLs localhost
- Webhook non reçu → Utiliser ngrok
- Payment URL timeout → Token expiré (>10 min)

================================================================================
  STATUTS TRANSACTION
================================================================================

INITIATED → En attente utilisateur
PENDING   → En cours (user a cliqué "Confirmer")
EXPIRED   → Token expiré (>10 min)
SUCCESS   → ✅ Payé
FAILED    → ❌ Échoué
