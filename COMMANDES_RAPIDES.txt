from django.core.files.base import ContentFile

inquiry = ClientInquiry.objects.create(
    kind="KIT",
    contact_name="Alice Martin",
    email="test@example.com",
    organization_name="Mairie de Test",
    context_text="Administration publique, 50 agents",
    payment_status="PAID",
    processing_state="PAID"
)

doc_text = """RÈGLEMENT INTÉRIEUR

Article 1 : Organisation
- Service finances
- Service urbanisme  
- Service état civil

Article 2 : Contrôles
Audits annuels obligatoires.

Article 3 : Documents obligatoires
- Registre des délibérations
- Livre de comptes
- Inventaire du patrimoine
"""

doc = InquiryDocument.objects.create(inquiry=inquiry, original_name="reglement.txt")
doc.file.save("reglement.txt", ContentFile(doc_text.encode()))

print(f"\n✅ Demande #{inquiry.pk} créée !\n")

================================================================================
🐛 DÉPANNAGE EXPRESS
================================================================================

Erreur "OPENAI_API_KEY not configured"
---------------------------------------
→ Vérifiez .env et redémarrez Django


Erreur "Cannot connect to redis"
---------------------------------
→ docker start auditshield-redis
→ docker ps (vérifier que Redis tourne)


Task bloquée en "IA_RUNNING"
-----------------------------
→ Vérifiez Terminal Celery (logs d'erreur)
→ Vérifiez OpenAI usage : https://platform.openai.com/account/usage


Celery ne démarre pas
----------------------
→ Vérifiez Redis : docker exec auditshield-redis redis-cli ping
→ Vérifiez .env : CELERY_BROKER_URL=redis://localhost:6379/0


Brouillon vide ou mal formaté
------------------------------
→ Consultez les logs dans GeneratedDraft.log
→ Vérifiez le modèle utilisé (doit être gpt-4o-mini ou supérieur)

--------------------

Redis au démarrage Windows
---------------------------
docker update --restart=always auditshield-redis
