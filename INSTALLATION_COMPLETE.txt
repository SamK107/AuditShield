1️⃣  CONFIGURATION (.env)

   Ajouter dans votre fichier .env:

   ORANGE_CLIENT_ID=your-client-id-here
   ORANGE_CLIENT_SECRET=your-client-secret-here
   ORANGE_APPLICATION_ID=your-app-id-here

   # Merchant
   ORANGE_MERCHANT_KEY=your-merchant-key-here
   ORANGE_MERCHANT_MSISDN=223XXXXXXXX
   ORANGE_MERCHANT_AGENT_CODE=your-agent-code

   ORANGE_RETURN_URL=http://127.0.0.1:8000/payments/om/return/

2. Créer une application "Orange Money WebPay"

   - merchant_msisdn
   - agent_code (si applicable)

================================================================================
  TROUBLESHOOTING
================================================================================

❌ "Variables manquantes dans .env"
   → Vérifier ORANGE_CLIENT_ID, ORANGE_CLIENT_SECRET, ORANGE_MERCHANT_KEY

❌ "Erreur d'authentification OAuth"
   → Vérifier les credentials sur developer.orange.com
   → Vérifier que l'application est "Active"

❌ "Erreur API Orange Money (code XXX)"
   → Vérifier ORANGE_MERCHANT_KEY
   → Consulter logs/orange_money.log

❌ Webhook non reçu en local
   → Utiliser ngrok: ngrok http 8000
   → Configurer OM_NGROK_URL dans .env
